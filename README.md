# Embedded Linux Study

## Overview

This repository documents my learning journey in Linux fundamentals, C system programming, and Embedded Linux development.

The long-term goal is to build a foundation for hardware–software integration, including FPGA-based acceleration and real-time signal processing applications.

## Learning Objectives

- Understand Linux commands, filesystem structures, and permissions.
- Develop and debug C programs in Linux.
- Learn process management, multithreading, and inter-process communication.
- Understand Embedded Linux boot processes and system architecture.
- Explore cross-compilation and hardware interfaces.
- Apply Linux programming to FPGA and signal processing projects.
